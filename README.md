# Sérénité

Appli Android perso de bien-être mental, inspirée des TCC (contenu original, 100 % local).

- **Humeur** : check-in (5 niveaux, émotions, facteurs, note), courbe 7/30/90 j, émotions fréquentes, impact des facteurs.
- **Journal** : libre, trois gratitudes, question du jour.
- **Exercices** : fiche de pensée (restructuration cognitive), 12 pièges de pensée, activités ressources (activation comportementale), 5 rythmes de respiration animés, ancrage 5-4-3-2-1, relaxation progressive, scan corporel.
- **Parcours** : 4 programmes de 7 jours (stress, anxiété, sommeil, bienveillance), un jour débloqué par jour.
- **Rappels** : check-in, journal du soir, parcours. Export / restauration JSON. Numéros d'aide (BE).

Build : GitHub Actions → Release `Serenite-1.0.N.apk` à chaque push sur `main`. Signature : `signing/serenite.jks` (dépôt privé).
